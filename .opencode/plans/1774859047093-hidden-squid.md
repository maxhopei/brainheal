## Summary of Changes

Five orthogonal work streams:

1. **`src/` reorganisation** — move TS source into `src/` for `worker/`, `packages/shared/`, and both Edge Functions (with thin shim `index.ts` at root).
2. **`.env.example` files** — create for every workspace that can be run (worker, frontend, both edge functions).
3. **`README.md` files** — create for every workspace + the repo root.
4. **`compose.yaml`** — cover worker + frontend (nginx/static), wire to `docker:*` deno tasks.
5. **AGENTS.md updates** — reflect new layout, task names, and dev workflow.

#### `supabase/functions/stripe-webhook/`

### 4. `compose.yaml` + Deno Tasks

#### `compose.yaml` (root)

Services:
- **`worker`**: builds from `worker/Dockerfile` (context: repo root), env from `worker/.env`, depends on nothing (Supabase is external), port 8080:8080
- **`frontend`**: builds from `frontend/Dockerfile` (multi-stage: Deno builds → nginx serves), env build args `VITE_SUPABASE_URL` + `VITE_SUPABASE_ANON_KEY` (read from `frontend/.env`), port 3000:80

```yaml
services:
  worker:
    build:
      context: .
      dockerfile: worker/Dockerfile
    env_file: worker/.env
    ports:
      - "8080:8080"
    restart: unless-stopped

  frontend:
    build:
      context: frontend
      dockerfile: Dockerfile
      args:
        - VITE_SUPABASE_URL
        - VITE_SUPABASE_ANON_KEY
    env_file: frontend/.env
    ports:
      - "3000:80"
    restart: unless-stopped
```

#### `frontend/Dockerfile`
Multi-stage build:
```dockerfile
# Stage 1: build
FROM denoland/deno:2.2.2 AS builder
WORKDIR /app
COPY . .
ARG VITE_SUPABASE_URL
ARG VITE_SUPABASE_ANON_KEY
ENV VITE_SUPABASE_URL=$VITE_SUPABASE_URL
ENV VITE_SUPABASE_ANON_KEY=$VITE_SUPABASE_ANON_KEY
RUN deno task build

# Stage 2: serve
FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
```

We also need a `frontend/nginx.conf` for SPA routing (try_files fallback to index.html).
