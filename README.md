# BrainHeal

AI-powered read-it-later app. Submit URLs or topics, get bite-sized swipeable cards generated by an LLM. Built as a PWA with real-time updates.

See [`specs/`](specs/) for full architecture and design documentation.

---

## Quick Start

### Prerequisites

- [Deno 2.7+](https://deno.com)
- [Supabase CLI](https://supabase.com/docs/guides/cli)
- [Docker](https://www.docker.com) (for the full stack)

### 1. Install dependencies

```bash
deno install
```

### 2. Start local Supabase

```bash
deno task supabase:start
```

### 3. Apply database migrations

```bash
deno task supabase:migrate
```

### 4. Configure environment

Copy and fill in `.env` files for each service (secrets are pre-filled for local Supabase):

```bash
cp frontend/.env.example frontend/.env
cp worker/.env.example worker/.env   # add LLM_API_KEY or AWS credentials
cp supabase/functions/ingest/.env.example supabase/functions/ingest/.env    # add LLM_API_KEY or AWS credentials
cp supabase/functions/stripe-webhook/.env.example supabase/functions/stripe-webhook/.env
```

The only value that requires a real secret is `LLM_API_KEY` in `worker/.env`.

### 5. Start everything

```bash
deno task start
```

This starts Supabase (if not already running) and brings up the worker + frontend via Docker Compose.

To stop:

```bash
deno task stop
```

### Run services individually

| Service | Command |
|---|---|
| Frontend (dev) | `deno task --cwd=frontend dev` |
| Worker (dev) | `deno task --cwd=worker dev` |
| Ingest function | `deno task fn:ingest` |
| Stripe webhook | `deno task fn:stripe-webhook` |

See each service's `README.md` for more details.

## Available Tasks

| Task | Description |
|---|---|
| `deno task start` | Start Supabase + Docker Compose (all services) |
| `deno task stop` | Stop Docker Compose + Supabase |
| `deno task docker:start` | Start Docker Compose services only |
| `deno task docker:stop` | Stop Docker Compose services |
| `deno task docker:build` | Build Docker images |
| `deno task docker:logs` | Tail Docker Compose logs |
| `deno task supabase:start` | Start local Supabase stack |
| `deno task supabase:stop` | Stop local Supabase stack |
| `deno task supabase:status` | Show Supabase service URLs and keys |
| `deno task supabase:migrate` | Apply database migrations |
| `deno task fn:ingest` | Serve ingest Edge Function locally |
| `deno task fn:stripe-webhook` | Serve stripe-webhook Edge Function locally |
