# @brainheal/shared

Shared TypeScript types for the BrainHeal monorepo. Used by all workspace members.

No runtime — pure type definitions. Import via the `@brainheal/shared` workspace alias.

## Usage

```typescript
import type { FeedItem, Card, QueueItem } from '@brainheal/shared';
```

## Running Tests

```bash
deno test --allow-all packages/shared/
```
